CHAPTER 3: AUTHENTICATION FLOWS (SPLIT INTO 3A & 3B)
================================================================================

--------------------------------------------------------------------------------
DIAGRAM 3A: User Credentials Verification Sequence (A4 Page 6)
--------------------------------------------------------------------------------
```mermaid
sequenceDiagram
    autonumber
    actor User as User Browser
    participant Portal as AuthPortal.jsx
    participant Auth as Supabase Auth Service
    
    User->>Portal: Select Role Card & Input Credentials
    Portal->>Auth: signInWithPassword(email, password)
    
    alt Auth Credentials Valid
        Auth-->>Portal: Return Session JWT Token
        Note over Portal: Proceed to Role Verification
    else Auth Credentials Invalid
        Auth-->>Portal: Return AuthError
        Portal-->>User: Display Error: "Invalid credentials"
    end
```

--------------------------------------------------------------------------------
DIAGRAM 3B: Database Role Verification & Routing Sequence (A4 Page 7)
--------------------------------------------------------------------------------
```mermaid
sequenceDiagram
    autonumber
    participant Portal as AuthPortal.jsx
    participant DB as profiles Table
    participant Router as React Router Engine
    actor User as User Browser
    
    Note over Portal: Session JWT verified
    Portal->>DB: Query profile row by auth.uid()
    DB-->>Portal: Return profile record (name, role, school_id)
    
    alt Selected Portal Role == DB Profile Role
        Portal->>Router: Redirect to Dashboard (/student-clearance, /admin-dashboard, etc.)
        Router-->>User: Mount and Render Dashboard Component
    else Selected Portal Role != DB Profile Role
        Portal->>Portal: Call auth.signOut() (Invalidate session tokens)
        Portal-->>User: Display Access Denied: "Role Mismatch"
    end
```

DIAGRAM 6B: Provisioning API Sequence & Trigger Lifecycle (A4 Page 14)
--------------------------------------------------------------------------------
```mermaid
sequenceDiagram
    autonumber
    actor Admin as Super Admin
    participant Form as AdminDashboard.jsx Form
    participant Client2 as Secondary Supabase Client
    participant Auth as Supabase Auth Service
    participant Trigger as Database Trigger: on_auth_user_created
    participant DB as profiles Table
    
    Admin->>Form: Enter name, email, password, role, school_id
    Admin->>Form: Click "Create User"
    Form->>Client2: signUp(email, password, options.data)
    Client2->>Auth: POST /signup with metadata
    Auth->>Auth: 1. Create authentication account
    Auth->>Trigger: 2. Fire trigger handle_new_user()
    Trigger->>DB: 3. Insert record (id, name, role, school_id)
    Auth-->>Client2: Return signup response (JWT session for new user)
    Client2-->>Form: Return success response
    Note over Form: AdminDashboard ignores the returned JWT.<br>Primary client remains active with Admin's session.
    Form-->>Admin: Display "User Created Successfully", refresh registry table
```
