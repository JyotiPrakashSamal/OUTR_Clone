4. JYOTI'S FLOWCHART (CORE SYSTEM ENGINE & DB ADMIN)
================================================================================
flowchart TD
    Start([Start: Browser opens application]) --> Platform_Boot[Initialize Router Engine & load Session configuration]
    
    subgraph "Client Utilities (i18n & Live API widgets)"
        Platform_Boot --> Check_i18n[Read localStorage UI translation key]
        Check_i18n --> Fetch_Locale[Fetch public/data/i18n JSON files & update DOM elements]
        
        Platform_Boot --> Check_AQI_Cache{Is local AQI cache < 15 min old?}
        Check_AQI_Cache -- "Yes" --> Read_Cache[Retrieve cached Open-Meteo AQI payload]
        Check_AQI_Cache -- "No" --> Fetch_API[Execute HTTP GET call to Open-Meteo air quality API]
        Fetch_API --> Store_Cache[Save fresh AQI measurements to browser localStorage]
        Read_Cache --> Render_AQI_Bar[Display colored AQI dashboard index in footer]
        Store_Cache --> Render_AQI_Bar
    end
    
    subgraph "Authentication & Security RLS Gateway"
        Platform_Boot --> Route_Dashboard[User navigates to React Dashboard SPA]
        Route_Dashboard --> Auth_Check{Is session user active in memory?}
        Auth_Check -- "No" --> Load_Auth_Portal[Render AuthPortal.jsx on route /portal]
        
        Load_Auth_Portal --> User_Login[Supabase Auth validation check]
        User_Login --> Auth_Trigger[Database Trigger: Run public.handle_new_user sync on profiles]
        Auth_Trigger --> Auth_Check
        
        Auth_Check -- "Yes" --> Query_Profiles[(Query public.profiles database table)]
        Query_Profiles --> Redirect_Dashboard[Redirect to role dashboard: admin/warden/student/etc]
    end
    
    subgraph "Database Transactions & Storage Sync"
        Redirect_Dashboard --> Execute_SQL[Execute SQL command: Select, Update, Insert]
        Execute_SQL --> Check_RLS_Policy{Match Postgres Row-Level Security rules?}
        Check_RLS_Policy -- "Deny Access" --> Return_DB_Error[Trigger database access control error exception]
        
        Check_RLS_Policy -- "Allow Access" --> Write_Postgres[(Perform SQL operations in Postgres database)]
        Write_Postgres --> Broadcast_Channel[Trigger dynamic update notifications via Supabase channel]
    end
    
    Render_AQI_Bar --> End([End: Application initialized])
    Return_DB_Error --> End
    Broadcast_Channel --> End
